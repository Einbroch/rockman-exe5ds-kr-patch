# 록맨 에그제 5 DS 트윈 리더즈 한글패치 분석

원본: `0099 - Rockman EXE 5 DS - Twin Leaders (J)(WRG).nds` 코드 A5TJ, SHA-256 0070ba09…, CRC 9FDF2ECE.
ARM9(비압축) 0x02000000 + 오버레이 425개. 게임 로직은 GBA EXE5 를 썸 코드로 옮긴 것.

## 텍스트
- 파일 `data/rom/{a,b,k}/*.msg`(raw 119개)와 `*_LZ.bin`(LZ10, 해제본 앞 4바이트 머리 + MSG) 합계 1,104 후보.
- TextPet 게임 `exe5ds`(cdbs mmbn5s,mmbn5ds) 왕복 일치 1,102/1,104(불일치 a_shl01·06 은 잡음).
- 12개 아카이브는 ARM9 에 박혀 있다(build.py STATIC). 파일 사본도 같이 갱신.
- GBA 번역 메모리가 일본어 글자 기준 89% 덮음. DS 전용 2,009줄: 자동 346 + translations/ds/*.tsv.

## 인코딩
- 유지: 00 빈칸, 01~0A 숫자, 67~99 라틴·기호, E4 00~2C(idx 0xE4+xx).
- 한글 1바이트(폰트 제자리): 0x0B~0x66, 0x9A~0xDD 160칸, 빈도순.
- 한글 2바이트: 리드 0xDE~0xE3 + 둘째 00~E3. idx = 0x1E4+(리드-DE)*228+둘째.
- 결과 스크립트 전체 크기 = 원본의 95.6%. DS 는 롬이 메모리에 안 보여 GBA 의 FA FD 점프를 못 쓰므로 크기가 곧 슬롯 안전.

## 엔진(tools/engine.py, ARM9 크기 불변)
- 폰트 0x0210F224(12×12 0x60), 0x02119784(8×16 0x40), 0x02120784(subfont, 0x40 잉크2·외곽1).
- 렌더러: 대사 0x020437C4·0x02043880·0x0204488C·0x02044940, 메뉴 0x02065016·0x02065092, 비례폭 0x0209D836, 타일 0x02012C84.
- 그리기: 0x02065410/0x020654BC(12×12), 0x0209D860(비례폭), 0x020650C8(8×16 칸 복사).
- 함정: 0x02065436 `movs r4,#0xb; push {r4}` 가 폭 고정 겸 행 카운터. 폭 12 를 그대로 쓰면 13행을 그려 3줄째가 첫 칸을 덮는다(GBA 와 같은 부류).
- 공간: 폰트 꼬리(idx >= 0x111)와 폭 표 꼬리.

## 슬롯
- 대사 계열(dm/st/rt 접미사별) 번역 최대 크기 < 원본 최대 크기.

## 타일 렌더러와 동적 칸
- 0x02012C84 는 폴더 편집 위 화면 칩 목록 등에서 쓰인다. 타일 번호 = 0x200 + 코드×2, 폰트는 subfont 앞 0x2B80 바이트(0~0xAD)만 0x0620C000 에 올라간다.
- ko_tile: 한글·E4 글자를 동적 칸 112개(코드 0x0B~0x66, 0x9A~0xAD 자리)에 그린다. 표는 폭 표 2 꼬리(SPARE).
- 칩 코드 A~I 는 VRAM 코드 0x5E~0x66 칸을 직접 쓴다(타일 0x2BC~). 그래서 동적 칸 83~91번은 건너뛴다(실제 103칸). 안 그러면 칩이 많을 때 코드 글자가 한글로 바뀐다.
- 재업로드 판정: VRAM 칸이 ARM9 폰트 칸과 같으면 무효로 보고 다시 그린다. 업로드 8곳을 훅할 필요가 없다.

## 그림 글자
- dc/po??·wo??: NNS 셀(g=RGCN, c=RECN, a=RNAN, p=RLCN). tools/ncer.py 로 셀을 읽고 tools/gfx_cells.py SPEC 으로 그린다. 타일 데이터는 0x30 부터.
- db/bg????: 8bpp NCGR+NSCR. tools/gfx_bg.py. 쓰기 전에 타일 공유를 검사한다.
- 라벨을 칸 수대로 이어 붙이는 화면(a_subsave)은 원문 칸 수로 채운다(build.py OVERRIDE).
- a/t_moji.bin(무압축), b/icon40_lz.bin(머리 4바이트 뒤 타일), a/stop.pix(4bpp 띠).

## 파일 참조 찾기
- 파일 번호는 u32 로 참조하고, LZ 파일은 최상위 비트가 붙는다(`id|0x80000000`). 플래그를 빼고 찾아야 한다.
- 적재 목록 레코드: (id, 목적지, 크기) 또는 (id, 0, 목적지). 0x02107688·0x02107740 은 블루스·카넬 판본별 목록이다.
- `b_`·`k_` 는 판본별 사본이다. `movemap` 처럼 둘 다 쓰이는 것이 있으니 라벨은 양쪽 다 고친다.
- `submenu` 는 0x0208C574 에 호출자가 없어 죽은 코드로 보인다. `b·k_logo00`, `coresult` 는 적재 기록을 못 찾았다. `collabo.msg` 도 같은 결론이 나왔으나 그 안의 칸 표 모양만 닮았을 뿐 실제 자판은 오버레이 416 이었으니, 이 판단은 화면 진입으로 확인되기 전까지 가설이다.

## 지도 화면(MAP DATA)
- 처리기 표 0x021030AC 11번. 상태 바이트 0x02168528 = 번호×4 (`tools/analysis/forcescr.py`, `scrsurvey.py`).
- 상태 구조 r5=0x02168538: +1 위치, +3 공개 지역 수, +5 설명 표시. 현재 지역이 네 곳 밖이면 위치가 4가 되어 강제 진입 시 L·R 로 멈추고 표지판이 깨진다. 정상 진입에서는 생기지 않는다.
- 맵 값-2 가 타일, 라벨은 21행 1~10칸. 타일을 movemap01 맵과 공유하지 않는지 확인한다.

## 지역 표지판 a/mapname_obj_lz.bin
- 해제본 앞 4바이트 머리, 타일 0x28부터 38칸, 칸 표는 내용으로 찾는다(10·1A·24·33 네 값). 항목은 (타일, x, y, 크기, 모양), 끝 FF.
- 원본은 秋原町·科学省·オラン島·エンドシティ 순으로 32·32·40·48px. 칸 표 순서만 바꿔 48·32·32·40px 로 준다(타일 수 불변).

## 통신 이름 입력(NAME ENTRY)과 NETWORK
- 들어가는 길: PET `통신` 단추(터치 212,50). 세이브에 이름이 있으면 NETWORK 로 바로 간다. 시험할 때는 새 롬 이름을 쓴다.
- 칸 표: 오버레이 416 파일 오프셋 0x17D6C, 60바이트 6벌(앞쪽·뒤쪽 × ゛·기본·゜). 행마다 왼쪽 5칸 + 오른쪽 5칸, 끝칸 0. 고른 바이트가 그대로 이름에 들어간다. `a/collabo.msg` 40~47 은 쓰이지 않는 듯하다.
- 그림: db/wbg0100(타일) + wbg0100·0101(맵 두 쪽), BG2 8bpp, 타일 0xC000~0x14000 = 최대 512칸. 현재 365칸.
- 이름 5칸, 코멘트 13칸. 자판 글자는 전부 1바이트 코드여야 해서 `kotext.assign(freq, namekb.KEEP)` 로 음절 90자를 1바이트에 고정했다. 스크립트가 원본의 97.4% 로 늘었고 slots.py 기준 초과 0건(a_dm060d 는 번역을 줄여 맞춤).
- `tools/namekb.py`: 8bpp 그림은 픽셀로 풀어 고친 뒤 다시 자른다(`rebuild`). OBJ 는 `cell_paint`.
- 선택 상태 단추는 wo02 셀 7·8·9, 통신 단추는 wo03 셀 8·9·40, 예/아뇨는 wo02·wo03·wo05, 트레이드 정렬창은 wo04 셀 28.
- 무선 연결 뒤의 화면(대전 목록 채움, 트레이드 진행)은 상대가 없어 못 봤다.

## 내장 아카이브 크기
- STATIC 아카이브는 원본 크기를 넘으면 ARM9 에 넣을 수 없다. 넘치면 일본어 바이트가 남아 뜻 없는 한글로 나온다(칩 설명에서 실제로 발생). 이제 빌드가 멈춘다.
- 자판 음절 고정으로 a_chipinf0 이 40바이트 넘쳐 `칸`, `앞` 을 1바이트에 함께 고정했다.

## 리버레이트 시험 경로
- work 의 사슬: mktest(fc030800e6) → walk → libwarp(86 0) → 안내 A 연타 → 커맨드 창에서 B → 왼쪽 위 다크 패널 → 리버레이트.
- 적 HP 는 u16 쌍 (값, 값). 맵 바탕 패널: 파랑=일반, 분홍=다크.

## 시험 롬 명령
- 전체 칩 지급 `F4 15 02`, 칩 트레이더 `FB 06 03 01`. mktest 페이로드 예: `f41502fb060301e6`. 전체 칩 상태로 폴더 편집 목록을 끝까지 내려 본다(R 로 쪽 이동).
- t_moji 는 OBJ 타일 = 파일 타일 + 1. `タイム` 240, `リーダー` 220.

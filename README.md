# 록맨 에그제 5 DS 트윈 리더즈 한글패치

닌텐도 DS 「ロックマンエグゼ5DS ツインリーダーズ」(일본판, A5TJ) 한글패치 작업 폴더.
GBA 판 에그제 5 한글패치의 번역을 옮기고, DS 전용 문장 2,009줄을 새로 번역했다. 분석은 [docs/analysis.md](docs/analysis.md).

> 롬은 저장소·배포물에 넣지 않는다(`.gitignore`). 배포는 xdelta 패치만.
> 패치한 롬은 원본보다 작다(뒤쪽 빈 공간이 줄어든 것으로 정상).

## 들어간 것
- 대사·메뉴·칩 이름/설명·메일·게시판·튜토리얼 전부(스크립트 원문 미번역 0줄, 빌드가 게이트로 막는다).
- 한글 1,246음절. 대사 12×12(갈무리11), 메뉴 8×16(에그제 1 한글판 글꼴).
- 그림 글자 약 140개: PET 메뉴·하위 화면 라벨, 서브칩, 폴더·폴더 편집 제목과 단추, 칩 정렬창, 메일·키 아이템, 타이틀 로고(`록맨 에그제 5 DS 트윈 리더즈`), 리버레이트 카메라 안내·안내 띠, 전투 결과 창, 칩 트레이더, 지도 화면(표지판·라벨, 블루스·카넬 판본), 통신 이름 입력 한글 자판, NETWORK 메뉴·통신 단추, 넷내비 화면 제목, 미니게임 안내, 타이틀 불러오기 화면, 맵 진입 띠, 통신 화면 일부.

## 확인한 것(에뮬레이터 py-desmume)
- 콜드 부팅 → 팀 선택 → 오프닝 → 넷토 방 → 집 안 이동까지 정상 진행.
- **시험 롬으로 건너뛴 구간**: 엄마와의 대화 트리거를 못 맞춰 플러그인 플래그 검사를 건너뛴 시험 롬으로 넷토의 HP에 들어갔고, 전투도 시험 롬으로 강제 진입했다. 커스텀 화면, 칩 사용, 피격·위기 상태, 게임 오버, 타이틀 복귀까지 멈춤 없음.
- PET 메뉴 9개 하위 화면, 칩 폴더, 폴더 편집(위 화면 칩 이름은 VRAM 동적 칸).

## 알려진 문제·확인하지 못한 것
- 쓰이지 않는 것으로 보여 그대로 둔 그림: `b·k_submenu`(적재 함수 호출자 없음, PET 단추 9개 실행 기록도 0회), `b·k_logo00`, `a/coresult.bin`(적재 기록을 못 찾음). 확정은 아니다.
- 이름 입력 자판에 없는 음절은 넣을 수 없다. 90자로 한정돼 있다.
- 무선 통신은 상대 기기가 없어 연결 전 화면까지만 봤다. 대전 목록이 찬 화면, 트레이드 진행, 상대에게 보이는 이름은 미확인.
- 화면으로 못 본 라벨: 패배 창 `칩 데이터 분실...`, 칩 트레이더, 카넬 판본 지도 라벨, `도감 비교`·`기록 비교`, 트레이드 정렬창, 통신 예/아뇨, 불러오기 화면 `이어하기`·`컨버트`.
- 전투 승리는 적 HP 를 메모리에서 0으로 만들어 본 것이다.
- 리버레이트 미션은 튜토리얼, 다크 패널 해방 전투, 승리, 미션 맵 복귀까지 봤다. 미션 끝까지와 후반 진행은 화면으로 못 봤다. 대신 번역문 29,892개의 줄 폭·줄 수를 `tools/gate_width.py` 로 전수 검사했고(문제 0), 대사 슬롯은 계열별 크기 비교로 막았다.
- 동적 칸은 112개다. 한 화면에 서로 다른 글자가 그보다 많으면 잠깐 틀린 글자가 나올 수 있다.
- KS X 1001 밖 음절 2자(햣·쌰)는 메뉴 글꼴에 없어 메뉴 칸에선 비어 보인다(대사 전용).
- 실기·melonDS 는 미확인.

## 다시 만들기
```bash
python tools/unpack.py "0099 - Rockman EXE 5 DS - Twin Leaders (J)(WRG).nds" work/jp
python tools/scan_msg.py
python tools/patch_plugins.py
python tools/decode_all.py
python tools/autotr.py
python tools/compile_ds.py
python tools/build.py --release build/rel.nds
```
`translations/ds_src.json`(원문 덤프)은 저장소에 없다. 번역 수정 단계(`autotr.py`, `compile_ds.py`)에만 필요하고, `build.py` 는 저장소의 `translations/ds/*.json` 으로 돈다.

필요한 것: 파이썬 ndspy·keystone-engine·capstone·pillow, TextPet(`external/`, 저장소에 없음), `../Rockman exe 5` (GBA 번역), `../Rockman exe 4.5/external/fonts/Galmuri11.bdf`, `../Rockman exe 2/Battle Network Rockman EXE 1 [K].gba`.

## 한글 자판
PET `통신`의 이름 입력은 한글 자판이다. 두 쪽에 음절 90자와 숫자·기호를 넣었고 `다음쪽`/`앞쪽`으로 넘긴다. 칸 하나가 1바이트로 저장되므로 자판에 없는 음절은 입력할 수 없다. 음절 목록은 `tools/namekb.py` 의 `NAMES`·`OTHERS` 에 있다.
